## Overview

This patch release is a maintenance and security release. It resolves every
dependency advisory that has a patched version available upstream, **including both
critical advisories**, and restores the Token Contract CI workflow, which had been
non-functional since 2026-04-16.

The release also carries the wind v2.0 design packages developed since `v1.2.1` —
foundation load envelope, tilt-up erection kinematics, and an Arctic direct-drive
powertrain — plus the archival of the v1.0 sail designs.

**No physical design claim is made or withdrawn by this release.** The wind work
below remains at concept and desk-study stage. What changed is that the CI which
would catch dependency problems now actually runs.

### Why `overrides` for `ws` and `serialize-javascript`

Both are transitive dependencies, so there is no direct version to bump. `mocha` 12
would pull `serialize-javascript@7` legitimately, but `mocha` is pinned to `^10.2.0`
by both `eth-gas-reporter` and `solidity-coverage`; upgrading it would violate two
Hardhat plugin ranges. Overriding the leaf dependency is the smaller, safer change.

Compatibility was verified rather than assumed. `serialize-javascript` 6 and 7 both
export a single function via `module.exports`, not an object exposing
`.serialize`/`.deserialize`. Mocha invokes it directly at
`lib/nodejs/buffered-worker-pool.js:162`, so the forced major bump is API-compatible.
Confirmed by round-tripping an options object through the installed 7.1.2.

## Token Contract CI restored

The workflow had not executed successfully since **2026-04-16**. Six independent
causes were found and fixed:

1. **Branch filter mismatch.** Triggered on `main` while the default branch is
   `master`, so no push ever matched.
2. **`actions/upload-artifact@v3`** — retired by GitHub in January 2025. Would have
   failed at the final step even if triggered.
3. **`actions/checkout@v3` and `actions/setup-node@v3`** — Node 20 forced-migration
   warning from GitHub's runners.
4. **`node-version: '18'`** — Hardhat 3 requires Node ≥ 22.13.0 and refuses to run
   below it.
5. **`package-lock.json` excluded by `.gitignore`.** Both `npm ci` and the
   `cache: 'npm'` option on `setup-node` require it. The `.gitignore` rationale
   described it as leftover from an earlier Ethereum project, but `contracts/` and
   `test/` are tracked and the CI workflow builds both.
6. **`hardhat.config.cjs` invisible to Hardhat 3.** Hardhat 3 recognises only
   `hardhat.config.js` and `hardhat.config.ts`. The project was running
   `hardhat ^3.4.1` against a Hardhat 2 config. Renaming also required converting
   CommonJS `module.exports` to ESM `export default`, since `package.json` declares
   `"type": "module"`.

**Why this matters more than a broken build:** while the workflow was non-functional,
no dependency advisory in this project could have been caught by CI. The four open
alerts above existed undetected for roughly six months.

The workflow now runs on every push to `master` and on pull requests targeting it, and
completes green.

## Wind v2.0 design packages

Development continued on the containerised Arctic turbine. Three of four packages
have deliverables.

- **Package 1 — foundation and Arctic ground** (#85). Load envelope analysis, OpenSCAD
  CAD model, and renders.
- **Package 2 — mast and tilt-up erection** (#86). Erection kinematics, OpenSCAD
  model, and renders.
- **Package 3 — Arctic direct-drive powertrain and nacelle** (#87). Operating
  envelope, OpenSCAD model, renders, and a hyperlinked glossary of powertrain terms.
- **Package 4 — sectional rotor, anti-icing, microgrid** (#88). Not started.

### v1.0 sail designs archived

The v1.0 sail designs are preserved under
`cad_and_blender/openscad/wind/archive/v1.0/`. Two findings retired them:

- **Every nominated working fluid freezes solid at −60 °C** — saturated NaCl brine
  (−21 °C), CaCl₂ brine (−30 °C), and 60% glycol (−48 °C). A liquid column approach
  is not feasible at the design cold.
- **The sail cannot sustain self-excited oscillation.** Aerodynamic damping measures
  0.014%–0.656% of structural damping, so it behaves as a static deflector with no
  usable motion to convert.

[`WIND_MASTER_INDEX.md`](../../_z_archives/wind/WIND_MASTER_INDEX.md) remains the consolidated tracker. Note that its purpose
framing predates the containerised-turbine pivot; the v2.0 README under
`cad_and_blender/openscad/wind/v2.0/` is current for design intent.

**These remain concept and desk-study artefacts.** No package has been physically
built or tested. The programme's primary blocker is unchanged: site mean wind and
speed distribution have not been supplied, and rotor sizing scales strongly with
mean wind.

## Upgrade notes

- **`package-lock.json` is now tracked.** It was previously gitignored. Any process
  that assumed a clean clone had no lockfile will now see one. `npm ci` requires it.
- **`hardhat.config.cjs` is now `hardhat.config.js`,** with ESM syntax. Any script
  referencing the old filename needs updating.
- **Node 22 is now required** to build contracts. Node 20 and below will not run
  Hardhat 3.
- **No public API, endpoint, or deployed asset changed.** The published site is
  unaffected.
