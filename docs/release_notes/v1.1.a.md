## Overview

v1.1.a adds an OpenCode-authored parametric AMU model and CORA-M variant for issue #5, iterated across 45 commits on September 16–17, 2026. These are TRL 1 concept sketches, not validated manufacturing or robotics systems. The work progressed from a heritage-matched baseline through rail/docking geometry, a CORA-M (Mobile) variant with grasp rivets, and a caliper tow runway, driven by rapid visual feedback loops with renders committed alongside the source.

## Limitations and Follow-Up

- Final runway clearance is not certified: `f4954ed` still includes a separate top-spine rivet loop without the lane exclusion, and the depression translation references `cx` outside its runway loop. These source observations require follow-up; no CAD fixes are included in these notes.
- `SHOW_CORA_PATH=false` by default. Space ROS / Gazebo import and final STL export remain follow-ups in issue #5, not verified integrations delivered here.
- The palette is color-matched OpenSCAD geometry, not true PBR rendering or validated structural design.
- The archived `amu_opencode_v1-09-16-2026-2331-est.png` is an empty file at `f4954ed`.
