## Overview

This patch release builds on the v5 sail concept from `v1.2`. It adds a static
build123d geometry port and regression checks, an idealised winter-stability screen,
clearer limits for the motion model, reproducible model-check instructions, and a
physical-validation protocol.

These additions improve model inspection and make the remaining engineering questions
more explicit. They do **not** establish that the physical sail will oscillate, remain
stable in winter, withstand design loads, or generate power.

## Changes

- **Static build123d port.** Added
  `amu_wind_sail_v5_build123d.py` as a static geometry port of the OpenSCAD v5 model.
  It reports connected geometry islands and distinguishes expected from unexpected
  disconnected parts. A deliberate displacement check confirms that moved geometry is
  detected. The OpenSCAD file remains authoritative; the port does not reproduce its
  animation or engineering analyses.
- **Idealised winter-stability screen.** Added a configurable margin threshold of 2.0
  and diagnostics that report the current equation-based margin and corresponding
  `ICE_TOP` limit. For the current parameters, the screen limit is approximately
  `0.300 m`. It is not a structural safety factor, a thermal model, or certification,
  and winter ice growth is not controlled by the model.
- **Honest motion-model scope.** Clarified that wind mode applies prescribed drag
  forcing in a single sail-angle coordinate. It does not solve airflow feedback,
  sloshing, structural flex, or power conversion. Animation and equilibrium outputs
  are equation/model illustrations, not physical performance evidence.
- **Reproducible checks and assets.** Documented copy/paste checks for the wind-response
  mode and added reviewed wind-response MP4s with contact sheets.
- **Physical-validation protocol.** Documented how to test self-start from rest
  separately from sustained rocking after a perturbation, including a repeatability
  criterion. No physical test has yet been run.

## Open engineering work

The operating principle remains unproven. Physical motion, design wind cases and load
capacity, cold-weather performance, serviceability closure, and the project acceptance
criteria remain open. See the canonical [#82 Next steps comment](https://github.com/stellardreams/asi.surge.sh/issues/82#issuecomment-6053782130)
and [risk register](https://github.com/stellardreams/asi.surge.sh/issues/82#issuecomment-6051591627).
